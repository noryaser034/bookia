## 🌍 Overview

**Bookia** is a modern bookstore application built with Flutter, featuring clean architecture, API integration, and full support for Arabic & English.

---

## ✨ Features

- 🌍 Multi-language (Arabic & English)
- 🔐 Authentication (Login / Register / OTP / Reset Password)
- 📚 Books browsing & details
- 🔍 Smart search
- 🛒 Cart & Wishlist
- 📦 Orders system
- 👤 Profile management
